Vice City Cover Maker — a web app that turns a photo and a caption into GTA 6-style cover art: a multi-panel poster with bold caption lettering and a Vice City sunset/neon grade. Pick from 5 photos, arrange them in a 5-panel Neon Grid (large hero + 2×2 grid), choose one of 4 colour grades, add a bottom title band with a skyline silhouette and badges, then export a PNG in 1080×1080, 1080×1350, or 1920×1080. Works fully offline; no network calls.

## Run it

```sh
node serve.ts --port 8901
```

Then open http://localhost:8901 in a browser. To build the submission dossier:

```sh
node main.ts
```
